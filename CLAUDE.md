## 작업 방식: 오케스트레이터 + 서브에이전트

메인 세션은 **오케스트레이터**로 동작한다.  아래 위임 규칙에 따라 서브에이전트에 위임하고, 결과를 검증·통합하는 역할에 집중한다.

### 위임 규칙


| 작업 종류                              | 처리 방식                                                            | 모델     |
| ---------------------------------- | ---------------------------------------------------------------- | ------ |
| 코드베이스 탐색/검색 (구조 파악, 심볼 찾기, 사용처 추적) | `Explore`서브에이전트에 위임                                              | sonnet |
| 파일 수정/구현 (기능 구현, 리팩터링, 테스트 작성)     | `code-writer`서브에이전트에 위임                                          | sonnet |
| 구현 계획 수립                           | `Plan` 서브에이전트에 위임                                                | opus   |
| 리뷰                                 | `reviewer` 서브에이전트에 위임                                            | opus   |
| 회귀 검증 (커밋 전)                       | `regression-verifier` 서브에이전트에 위임                                 | sonnet |
| 오케스트레이터가 직접 하는 것                   | 작업 분해, 서브에이전트 프롬프트 작성, 결과 검증, 사용자와의 대화, OpenSpec 아티팩트 관리, git 커밋 | -      |
