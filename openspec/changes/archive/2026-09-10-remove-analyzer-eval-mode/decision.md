# 결정 기록

- 채택한 안: **모드 분기를 없애고, "입력에 사용자 후보가 있으면 그것도 안 하나로 포함해
  같은 형식으로 평가한다"는 문장 하나로 흡수한다.**
- 결정한 사람: 오케스트레이터 (사용자가 방향을 지시하고 판단을 위임함)
- 결정 날짜: 2026-09-09
- analyzer 추천안: 해당 없음 (analyzer 생략 경로 — 사용자가 방향을 이미 정했다)

## 채택 이유

사용자가 낸 아이디어를 검토하는 일은 analyzer의 원래 일("요구사항 + 코드 → 방안 N개 +
장단점 + 의견")과 **같은 일**이다. 안이 하나 더 늘 뿐이다.

별도 모드로 분리해 둔 대가는 세 가지였다:

1. `analyzer.md`에 절 하나(20여 줄)와 조건부 RESULT 필드 `feasible=<평가 모드일 때만: ...>`
2. `orchestra/SKILL.md`에 왕복 분기 하나
3. 사용자가 안을 낼 때마다 opus 에이전트 추가 호출

없애도 **안전장치는 사라지지 않는다.** "검증 안 된 안으로 설계에 들어가지 않는다"는 보장은
"analyzer를 (유일한 방식으로) 다시 불러 사용자 후보를 안 목록에 넣고 평가받는다"로 그대로
유지된다. 바뀌는 건 그게 **특별한 모드가 아니라 평소 하던 일**이 된다는 것뿐이다.

## 채택하지 않은 안과 그 이유

analyzer를 거치지 않은 경로라 analysis.md가 없다. 검토 과정에서 배제된 방향은 다음과 같다.

- **평가 모드를 그대로 두고 문구만 다듬기** — 대가 세 가지(위 목록)가 그대로 남는다.
  이번 요청("쓸데없는 것 제거하고 딱 효과적으로 동작할 프롬프트만")과 정면으로 어긋난다.
- **평가 절차를 orchestra 쪽으로 옮겨 오케스트레이터가 직접 검증** — 오케스트레이터가
  코드를 읽고 판정하게 되어 CLAUDE.md의 위임 규칙("분석은 서브에이전트에게")을 깬다.
- **평가 자체를 없애고 사용자 안을 바로 designer로** — proposal의 받아들일 조건 4번
  ("검증 안 된 안이 설계에 안 들어간다는 안전장치가 문서에 남아 있어야 한다")을 위반한다.
  worker가 벽에 부딪히는 사고를 그대로 되살린다.

## 핵심 결정

1. `analyzer.md`에서 모드 개념을 완전히 제거한다. 남는 동작은 **하나**다 —
   요구사항 + 코드베이스 → 방안 최소 3가지 + 장단점 + 의견.
2. 사용자 후보의 처리는 `### 3. 방안 최소 3가지 만들기` 안의 **짧은 규칙 하나**로 흡수한다.
   살릴 값이 있는 알맹이는 세 가지뿐이다:
   - 사용자 후보도 안 하나로 넣어 **같은 형식**으로 평가한다
   - **성립하지 않으면 분명히 말한다** — 무엇이 막는지 파일:줄로 짚는다
   - 기존 안을 지우지 말고 **번호를 이어 붙인다**
   나머지(모드 판별, 절차 6단계 나열)는 버린다.
3. RESULT의 `feasible=` 필드는 버린다. 각 안마다 이미 "요구사항 충족" 항목이 있어 중복이다.
4. `orchestra/SKILL.md`의 안전장치 절은 **없애지 않고 호출 형태만 바꾼다.**
   "평가 모드로 다시 부른다" → "평소와 같은 형태로 다시 부르되 프롬프트에
   `사용자가 낸 안:`을 추가 후보로 얹는다". **"검증 안 된 안을 설계하면 worker가
   벽에 부딪힌다"는 이유 문장은 그대로 남긴다** — 그게 안전장치의 근거다.
5. `README.md`는 손대지 않는다. preparer가 확인한 대로 평가 모드를 언급하지 않는다.
6. `docs/verification-2026-09-08.md`도 손대지 않는다. 날짜가 박힌 **과거 기록**이라
   당시 상태를 그대로 보존하는 것이 맞다.
7. 대상 파일은 **반드시 `Edit`로 부분 수정한다.** 이번 세션에 리치 마크다운 편집기가
   `[[ORCA_RICH_MD:...]]` 토큰 삽입·굵게 표시 밀림·들여쓰기 붕괴를 낸 사고가 있었다.
   전체 `Write`는 같은 결과를 낸다.
8. **군살 빼기는 열거된 항목으로 한정한다.** analyzer.md는 이미 밀도가 높아, 모드 분기를
   빼고 나면 남는 제거 대상이 거의 없다. 목록 밖 문장을 임의로 지우면 회귀다.
